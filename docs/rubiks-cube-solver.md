# 魔方解答器

ToolBox 的“魔方”页支持普通贴纸配色的 3、4、5 阶正方体魔方，全程离线运行。

## 使用流程

1. 选择 3 阶、4 阶或 5 阶。
2. 固定一个前面和一个上面，严格按页面顺序拍摄前、上、右、下、左、后六面。
3. 每拍完一面，立即核对该面的识别示意图和实时累计颜色数量。红框表示低置信度色块，点按色块可循环纠正颜色；确认无误后再拍下一面。
4. 六面完成后再做一次总览。此时每种颜色的数量必须为 `N²`。
5. 点击“校验并生成复原步骤”。程序会先检查角块、棱块、中心和排列是否能来自真实魔方，再离线求解。
6. 保持拍摄时的持握方向，按“播放并继续”观看每一步 3D 层转动画。

## 求解方式

- 3 阶使用两阶段搜索，搜索表首次使用时生成并缓存到应用内部目录。
- 4/5 阶先归位中心块，再配对棱块，降阶成 3 阶求解，并自动处理大阶奇偶情况。
- 4/5 阶降阶搜索有 25 秒保护时限。极少数状态超时会明确返回失败，不会展示未经回放验证的步骤。

## 拍摄注意事项

- 魔方必须位于照片中央，完整露出四边，尽量正对镜头。
- 避免强烈反光、彩色环境光和跨越色块的阴影。
- 六张照片之间不可随意旋转魔方；面朝向错误会形成另一组看似合法但不对应实物的数据。
- 当前版本识别标准六色魔方（白、黄、红、橙、蓝、绿）；异形、镜面、图案和非标准颜色魔方不在支持范围内。

## 验证

本项目在 WSL Codex 中禁止运行 Android/Gradle 构建。请在 Windows Android Studio 或 Windows PowerShell Codex 中执行：

```powershell
.\gradlew.bat testDebugUnitTest
.\gradlew.bat assembleDebug
```

建议在真机上分别验证 3、4、5 阶逐面拍摄与即时纠色、累计颜色数量、拒绝相机权限、重拍、首次搜索表生成、内层/宽层动画及屏幕旋转后的行为。
