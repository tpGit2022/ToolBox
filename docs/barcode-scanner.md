# 二维码与条形码扫描

## 使用方式

在顶部选择“扫码”，点击“开始扫描”并授予相机权限。将二维码或条形码放入取景框，识别成功后自动返回并显示码制和原始内容，可以长按选择文字、复制完整内容、再次扫描或清除结果。扫描界面支持横竖屏，音量上键打开补光灯、音量下键关闭补光灯（需要设备支持闪光灯）。

使用 ZXing Android Embedded 4.3.0 在设备上解码，无需 Google Play 服务或在线识别。启用解码器提供的全部码制，包括 QR Code、Data Matrix、Aztec、PDF417、EAN、UPC、Code 39/93/128、ITF 等。

仅保存当前结果以支持切换标签页和界面重建，不建立持久化扫描历史，不保存相机图片，不自动打开网址或执行结果中的指令。取消扫描不会覆盖已有结果。复制时保留前后空白、换行及条形码的前导零。

## Windows / Android Studio 验证清单

该项目禁止在 WSL Codex 中执行构建。请在 Windows PowerShell（pwsh）中进入该项目目录，启动 Windows 环境下的 Codex，然后执行构建验证。

1. 同步 Gradle 并构建应用，确认新增依赖及相机 Activity 的 manifest 合并正常。
2. 在真机分别识别中文、多行文本、网址二维码和 EAN-13、Code 128 条形码；确认码制与原始内容正确，复制后仍保留换行和前导零，网址不自动打开。
3. 首次允许权限、拒绝权限、永久拒绝权限后进入设置授权，确认都能正确提示并重新启动扫描；无相机设备应显示提示，不影响其他工具。
4. 检查取消扫描不覆盖结果；切换其他标签再返回、旋转屏幕、进入后台再返回后，结果仍可查看；清除后恢复空状态。
5. 在扫码期间旋转屏幕、切换前后台，确认相机恢复正常；按返回键退出后相机占用释放；验证音量键补光灯和系统相机隐私开关关闭时的错误提示。
6. 断网识别二维码和条形码，确认不依赖网络；横竖屏检查取景框、提示及返回手势是否可用。
7. 在 Windows / Android Studio 运行 `BarcodeScannerScreenTest`，验证原文展示、复制/清除回调和空内容状态。相机识别、系统权限和真实剪贴板内容仍需真机验证。
